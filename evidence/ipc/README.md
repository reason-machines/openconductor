# IPC / backend (Wave 0, area 3, first pass)

- Process model (from `Resources/bin` shims and `ps`): Tauri main `MacOS/conductor` (Rust) + `bin/.internal/conductor-runtime` (Bun single-file executable, `__BUN` segment, 76 MB) run as `sidecar`, `logger`, `actions`, `internal`, `cli` subcommands. The `conductor` CLI is `conductor-runtime cli`. `agent-launcher` is a small native launcher; `gh` and `watchexec` are bundled.
- `tauri-plugin-commands.txt` - 147 `plugin:<name>|<cmd>` calls the frontend makes (fs, shell, sql, http, store, dialog, updater, notification, opener, deep-link, clipboard, window, webview, event, os, process, path, image).
- `frontend-invoke-candidates.json` - 151 snake_case literals the frontend passes as the first argument of a short (minified) call wrapper and that also appear as strings in the Rust binary, with the chunk(s) using each. Mostly custom `#[tauri::command]`s (`pty_*`, `rpc_to_sidecar`/`rpc_from_sidecar`, `ensure_sidecar_started`, `get_db_uri`, `*_keychain_setting`, `*_port_forward*`, `*_remote_file_sync*`, `native_http_*`, `raw_websocket_*`, agent-binary management, window chrome), but some are settings keys or event names that share the call shape. Bound to Rust functions in `ipc-rust-bindings.json` (below).
- `ipc-rust-bindings.json` - for each of the 151 candidates: `string_sites` (every exact byte occurrence in `__TEXT,__const`/`__cstring`, as a vm address), `handler_fn` (the `conductor_lib::<module>::<name>` path of the best local symbol ending in the name: plain fn > closure > drop glue of its async future > generic), and `referencing_functions` (functions whose ADRP+ADD pairs compute a string-site address; the function referencing the most names is a `conductor_lib::run` symbol at 0x100498360 with 10, likely part of the `generate_handler!` dispatch, which is an inference). Totals: 151 with a string site, 67 bound to a handler across 18 modules (17 plain fn, 8 closure, 41 drop glue, 1 generic), 112 with a referencing function. The 84 unbound are mostly settings keys and event names (`default_model`, `quit_requested`) plus commands that were likely inlined (`pty_kill`, `pty_resize`, `get_keychain_setting`, `quit_app`). Built by `tools/ipc_bindings.py` from `nm -U` (the binary is not stripped), not by REA, because REA's Ghidra `xrefs` costs ~32 min per address (REA gaps 13-14). Static, decoded from shipped bytes; not source.
- `rust-crates-from-paths.txt` - 210 crate@version names from panic-location paths in the binary (no cargo-auditable section exists).
