## User-facing correction

Keyboard users can open the Composer Add menu with ArrowDown or ArrowUp, focus the first or last available row, move through enabled rows with wrapping arrows, jump with Home/End, and close with Escape while returning focus to Add. Disabled Plan rows are skipped. Existing attachment, directory and Plan actions remain unchanged.
