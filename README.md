# openconductor
Open recreation of a parallel coding-agent desktop app, with Claude Code, Codex and Reason runtimes.

## Scope

Claude Code and Codex run locally on the user's Mac. Only Reason spans the Mac and a Reason cloud computer in one chat. Team, routines, triage, organization and cloud-workspace screens are deferred, not current parity requirements. Their retained UI must stay behind an Experimental setting that is off by default.

The [parity ledger](parity/ui-program/ledger.html) separates retained capture matches from fresh native final-review verdicts. [Regenerate the evidence queue](tools/ui-map/README.md) after each merge batch. A match in an older Chromium capture is not final native parity.
